# Data Visualization Plots

Generate publication-quality plots using matplotlib and seaborn, following the conventions in `.agents/skills/data-viz-plots/SKILL.md`.

## Instructions

1. Read `.agents/skills/data-viz-plots/SKILL.md` for style conventions (DPI, palettes, labeling, layout).
2. Write Python code following those conventions.
3. Execute using the project venv: `.venv/Scripts/python.exe`
4. Save output to the path specified by the caller (default: current run folder under `analyses/`).

## Arguments

`$ARGUMENTS` — description of the chart to generate, the data to plot, and the output path.
